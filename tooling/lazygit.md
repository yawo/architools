## lazygit

**Repository:** [jesseduffield/lazygit](https://github.com/jesseduffield/lazygit)
**Description:** A simple terminal UI for git commands.
**Key Features:**
- Terminal UI for common (and advanced) git operations without leaving the keyboard
- Stage/reset hunks and lines, commit, amend, and reword with ease
- Branch checkout, merge, rebase, and cherry-pick workflows
- Interactive diff view and file filtering
- Undo / redo for many operations
- Extensible with custom commands and keybindings
**Primary Use Cases:** Everyday git workflow in the terminal; reviewing diffs and managing branches without memorizing porcelain commands.
**Tags:** #git #tui #cli #developer-tools #version-control

### Notes / Why Notable
lazygit is one of the most popular Git terminal UIs (~80k+ stars). It wraps git porcelain commands behind a keyboard-driven interface, making staging hunks, amending commits, and resolving merge conflicts far more approachable. A staple developer tool for terminal-first workflows.
