## ha-mcp

**Repository:** [homeassistant-ai/ha-mcp](https://github.com/homeassistant-ai/ha-mcp)
**Description:** Unofficial Home Assistant MCP Server enabling natural language control of smart home devices.
**Key Features:**
- 92+ Tools: Comprehensive control of entities, states, automations, and scripts.
- Natural Language: Seamlessly interact with devices via AI assistants (Claude, Gemini, etc.).
- Real-time Updates: Uses Server-Sent Events (SSE) for responsive feedback.
- Easy Integration: Can be run as a standalone Docker container or via HACS.
**Primary Use Cases:** AI-powered smart home automation, voice-controlled home assistants.
**Tags:** #home-assistant #mcp #iot #smart-home #natural-language

### Notes / Why Notable
ha-mcp is the most powerful bridge between the Home Assistant ecosystem and the Model Context Protocol, allowing AI agents to have full structural and behavioral knowledge of a smart home environment.
