## EventMesh

**Repository:** [apache/eventmesh](https://github.com/apache/eventmesh)
**Description:** A dynamic event mesh that supports connecting multiple event stores and provides a unified event-driven architecture.
**Key Features:**
- Multi-store Support: Connects RocketMQ, Kafka, Redis, and more.
- Cloud-Native: Designed for Kubernetes and serverless environments.
- High Performance: Low-latency event delivery and massive throughput.
- Protocol Agnostic: Supports CloudEvents, gRPC, and HTTP protocols.
**Primary Use Cases:** Distributed AI systems, event-driven microservices, real-time data pipelines.
**Tags:** #event-mesh #messaging #cloud-native #apache
**Added:** 2026-06-18

### Notes / Why Notable
EventMesh is critical for building large-scale, distributed AI agent swarms that require reliable, cross-cloud messaging and event orchestration.
