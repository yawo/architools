## DASH (gh-dash)

**Repository:** [dlvhdr/gh-dash](https://github.com/dlvhdr/gh-dash)
**Description:** A rich terminal UI for GitHub that doesn't break your flow.
**Key Features:**
- Terminal UI for browsing and managing GitHub PRs, issues, and repositories
- Keyboard-driven navigation and actions (merge, close, comment, assign, label)
- Filters and search across your repos and organizations
- Branch-aware views and review workflows
- Works alongside the official `gh` CLI
**Primary Use Cases:** Managing GitHub pull requests and issues from the terminal without leaving your flow.

### Notes / Why Notable
DASH (gh-dash) is a popular GitHub terminal UI (~12k+ stars) for triaging PRs and issues directly from the command line. It complements `git` TUIs like lazygit for developers who live in the terminal. Homepage: [gh-dash.dev](https://gh-dash.dev).
